# EzGov-prototype-DXB311-AS3
Final high-fidelity working prototype for DXB311 AS3. EzGov is a simplified Government reporting platform designed to increase confidence among Australians aged 70+ when completing digital tasks.
To use the prototype, download the file and open 'Index.html' in your preferred browser. Google Chrome is the best browser for this prototype, as the TTS voice is coded specifically for that browser; other browsers will use a generic AI voice.
